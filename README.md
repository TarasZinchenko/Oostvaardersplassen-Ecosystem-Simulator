Project Overview: Oostvaardersplassen Wolf Introduction Simulation
This project investigates the potential impact of introducing grey wolves into the Oostvaardersplassen Nature Reserve in the Netherlands. The reserve faces challenges with herbivore overpopulation, particularly Red Deer, which is negatively affecting the ecosystem.

Using a mathematical model implemented in a Java application, we simulated predator-prey dynamics to predict ecological outcomes. The model incorporates factors like population growth, interspecies competition, and predation.

Our findings suggest that introducing wolves can help reduce the Red Deer population to more sustainable levels, thereby alleviating pressure on vegetation and benefiting other herbivores like Konik horses and Heck cattle.

The project also acknowledges potential risks, such as conflicts with humans and limitations of the model, emphasizing the need for careful planning and management.

This simulation tool aims to provide reserve managers with data-driven insights to support informed decision-making for sustainable ecosystem management.
